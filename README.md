# Uinen's Reminder

Телеграм-бот с напоминаниями, написанный на Python (telebot). Учебный проект (если хотите то тоже можете взять поюзать)

## Возможности

- `/rsec, /rmin, /rsec` — напомнить через N времени (напишите команду, чтобы увидеть шаблон)
- `/list` — показать все активные напоминания
- `/start` — приветствие и справка

## Как запустить

1. Установите зависимости:
   ```bash
   pip install pyTelegramBotAPI python-dotenv
2. Откройте rembot.py в любом редакторе кода с поддержкой Python
3. В переменной bot измените токен на свой:
   ```python
   bot = telebot.TeleBot('вставить токен сюда')
4. Запускать бота командой python rembot.py
5. Найти бота в Telegram по юзернейму: @uinrembot
