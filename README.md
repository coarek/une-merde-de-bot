# Uinen's Reminder

Телеграм-бот с напоминаниями, написанный на Python (telebot). Учебный проект (если хотите то тоже можете взять поюзать)

## Возможности

- `/rsec, /rmin, /rsec` — напомнить через N времени (напишите команду, чтобы увидеть шаблон)
- `/list` — показать все активные напоминания
- `/start` — приветствие и справка
